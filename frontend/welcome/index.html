使用说明

1选择入口

电脑或平板建议进 电脑完整版；手机直接进 手机版（两个入口共用同一账号与数据）。

2登录系统

演示账号 admin / 123（超级管理员）。正式环境请务必在「系统设置 → 用户管理」中修改默认密码。

3推荐演示动线

系统概览 → 数据管理（时间轴播放）→ 变化分析 → 预测建模（四情景对比）→ 报告生成 → 图图问答。

关于数据：内置「平朔矿区（真实）」数据集（CLCD 30 m 土地覆被 + DEM + 光谱指数，65.15 km²）与两个合成示范数据集；真实数据集的已知局限见 README 说明。
关于 AI 助手图图：回答会注入当前矿区真实统计与 30 节地信遥感知识库摘录，数字与数据库逐条核对，对不上会标注「未核实」。演示环境使用云端模型推理，本地部署版可完全离线、数据不出本机。
关于部署：本页所在服务器为云演示环境；软件另有 Windows 离线完整版（内置 Python 运行时与本地模型，无需联网安装）。
